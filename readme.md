# Map Reduce Tutorial

A short tutorial project I wrote for my CS 425 class in the 2021 spring
semester.

## Mapper Examples

This is the assumed starting point, and demonstrates the similarities between
iterative `for` loops and mapping, then building up to using parallel mapping to
do it much faster.

## Reducer Examples

This class contains functions that reduce an array by summing all the int values
in it. Like the Mapper Examples, it shows how this process works in a for loop,
then builds on that idea. The final function combines mapping and reducing to
show how they can be chained together.
